# もち連鎖

同じ色のもちを4つつなげて消す、ブラウザで遊べる落ちものパズルです。スマホでもPCでも遊べます。

## 遊び方

- 2個ひと組で落ちてくるもちを、回転させながら積みます。
- 同じ色が4つつながると消えます。消えたあとに落ちたもちがまた4つそろうと連鎖になります。
- 左から3列目のいちばん上（×の場所）まで積み上がったらおしまいです。

### モード

- **ひとりで**：どこまで続けられるかに挑戦します。色の数は3〜5色から選べます。
- **CPUと対戦**：連鎖すると相手におじゃまもちが降ります。CPUの強さは「よわい・ふつう・つよい」の3段階です。

### 操作

| | スマホ | キーボード |
|---|---|---|
| 移動 | 左右になぞる | ← → |
| 回転 | 右側／左側をタップ | Z・X（↑） |
| 加速 | 下になぞる | ↓ |
| 一気に落とす | 下にすばやく払う | Space |
| 一時停止 | 右上のボタン | P |

## ファイル

`index.html` 1つだけで動きます。外部のライブラリは使っていません（フォントのみ Google Fonts を読み込みます）。記録と設定はブラウザの localStorage に保存されます。
